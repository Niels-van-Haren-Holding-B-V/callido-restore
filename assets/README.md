# Artwork

* `logo-source.jpg`: original artwork made for this project (2026). It is not derived from Synology's Hyper Backup
  branding or any other third-party material, and the app is not affiliated with Synology.
* `logo.png` (512 px, transparent rounded corners), `logo-64.png` (embedded in `static/index.html`) and `AppIcon.icns`
  are generated from the source by `scripts/make_logo.py` (needs Pillow and macOS `iconutil`); do not edit them by hand.
